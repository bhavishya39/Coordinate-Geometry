# Coordinate Geometry Using Python

A Python project that aims to implement the concepts of coordinate geometry using Object-Oriented Programming (OOP).

## Overview

The goal of this project is to build a comprehensive coordinate geometry toolkit covering mathematical operations, geometric properties, and equations of curves.

## Features

### 1. Straight Line

* Different forms of line equations
* Slope and intercepts
* Intersection of lines
* Angles and distances

### 2. Circle

* Center, radius, area, and circumference
* Tangents and chords
* Intersections with lines and other circles

### 3. Parabola

* Vertex, focus, and directrix
* Eccentricity and latus rectum
* Tangents and normals

### 4. Ellipse

* Center and axes
* Foci and eccentricity
* Tangents and normals

### 5. Hyperbola

* Center, vertices, and foci
* Eccentricity and asymptotes
* Tangents and normals

## Technologies Used

* Python
* Object-Oriented Programming (OOP)
* Git and GitHub

## Project Goals

* Implement coordinate geometry concepts through Python classes.
* Apply OOP principles such as encapsulation, inheritance, and polymorphism.
* Develop reusable mathematical operations.
* Expand the project to cover advanced geometric concepts.
